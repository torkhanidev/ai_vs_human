# Last Stand 3D

This build is a lightweight Three.js crowd runner inspired by Count Masters-style gameplay.

## Project structure

```text
index.html
css/
js/
  core/game.js
  ui/mobile-bottom-dock.js
```

## Local test

Run through a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Notes

The project uses procedural in-game characters only. No external character model pipeline is required.
